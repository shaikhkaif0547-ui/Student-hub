STUDENTHUB - STUDENT RECORD MANAGEMENT WEBSITE

PAGES
1. Dashboard: view total students, average marks, highest marks and recent records.
2. Student Records: add, search, view and delete student records.

HOW TO RUN IN VS CODE (WINDOWS)
1. Extract this ZIP file.
2. Open the Student_Record_Website folder in VS Code.
3. Open Terminal > New Terminal.
4. (Recommended) Create a virtual environment:
   python -m venv venv
5. Activate it:
   venv\Scripts\activate
6. Install requirements:
   pip install -r requirements.txt
7. Run the website:
   python app.py
8. Open this address in your browser:
   http://127.0.0.1:5000

The SQLite database (students.db) is stored inside this project folder.
The existing student record from the supplied project has been retained.
